# ETKilit Mobil — web sürümü

iPhone'lu öğretmenler için: Safari'de açılıp **Paylaş → Ana Ekrana Ekle** ile uygulama gibi kullanılır.
Android'de APK sürümü önerilir.

- Öğretmen anahtarı (Ayar Kodu) **yalnızca telefonda** saklanır; bu site hiçbir veri toplamaz, sunucuya bir şey göndermez.
- Tahtadaki karekodu okutup çıkan 6 haneli kodu tahtaya yazın ya da 30 saniyelik kodu kullanın. İnternet gerekmez
  (ilk açılıştan sonra çevrimdışı çalışır).

Bu depo, ETKilit ana deposundaki `etkilit-mobil-web/` klasörünün kopyasıdır; değişiklikler orada yapılır.
Yayın: `main` dalına her gönderimde GitHub Actions `dist/` klasörünü üretip GitHub Pages'e koyar.
